# 需求文档

## 1. 应用概述

### 1.1 应用名称
启禾社区

### 1.2 应用描述
面向AI爱好者、创作者和项目探索者的AI社区网站，提供案例展示、AI项目库、城市组局、商务与合作、智能助手等核心功能，支持用户等级体系与经验值规则、付费项目等级额度解锁、活动报名与后台名单管理、统一后台内容与文案配置（含商务合作与页脚信息）。

## 2. 用户与使用场景

### 2.1 目标用户
- AI爱好者：浏览学习AI案例与项目，依据等级权益享受付费项目免费解锁，通过每日签到、点赞、收藏获取经验值，参与活动报名及查看商务合作信息。
- AI创作者：发布与探索优质AI项目、获得互动经验值奖励、参与线下活动及对接商务合作。
- 网站管理员：统一管理案例/项目/活动/商务合作内容、配置全站文案与页脚信息、管理用户权益与账号。

### 2.2 核心使用场景
- 用户在首页、AI项目库浏览内容，在项目卡片左上角直观查看付费类型与成熟度双标签。
- 用户进行每日首次签到、点赞、收藏获取经验值，并在个人中心查看详细的经验值获取规则说明。
- 用户点击顶部导航「商务与合作」浏览合作介绍与对接信息；管理员可在后台维护该板块内容并控制前台显示/隐藏开关。
- 管理员在后台修改页脚品牌描述与版权信息，前台页脚区域即时生效并同步展示。
- 用户访问付费项目详情页，通过等级免费额度弹窗完成解锁并查看剩余额度。

### 3.2 前台页面功能

#### 3.2.1 首页 - 案例展示
- 案例卡片图片保持 4:3 比例展示，整卡固定高度。
- 展示点赞量、收藏量、浏览量；点击点赞与收藏图标触发 gsap 缩放与红心粒子动效。
- 支持分类快速筛选与最新/最热排行榜。

#### 3.2.2 案例详情页
- 完整渲染富文本内容，展示浏览量、点赞量与收藏量，支持用户点赞与收藏。

#### 3.2.3 AI项目库
- **卡片固定高度与左上角双标签展示**：
  - 项目卡片图片保持 4:3 比例，整卡统一固定高度。
  - **卡片封面左上角标签**：同时展示两个小标签：
    - **付费类型标签**：依据后台设置的访问级别（免费/会员/Pro）动态展示对应标签。
    - **成熟度标签**：依据后台设置的成熟度状态（如成熟产品/概念/测试版等）动态展示对应标签。
  - 双标签排版紧凑清晰，与深色主题风格协调。
- 卡片提供「访问项目」按钮，支持点赞、收藏（附动效）及浏览量展示。
- 支持顶部场景、成熟度等标签及分类筛选。

#### 3.2.4 项目详情页
- 展示项目基本信息、外部链接与富文本详情。
- 付费项目未解锁时弹出「等级权益解锁」弹窗，展示当前等级、剩余免费额度，确认后扣减额度解锁。

#### 3.2.5 城市组局与详情页
- 卡片保持 4:3 比例与固定高度，提供详情查看与在线报名表单（姓名、电话、联系方式、备注）。

#### 3.2.6 商务与合作（新增）
- 位于顶部导航栏「城市组局」右侧。
- 展示平台商务合作介绍、合作类型、合作权益、联系方式及合作申请说明。
- 受后台「显示/隐藏开关」控制：若管理员关闭该开关，前台导航项及页面入口均隐藏，直接访问路径重定向至首页。

#### 3.2.7 账号管理与个人中心
- 登录/注册：支持基础注册与登录流程。
- **个人中心**：
  - **等级卡片与经验值进度**：展示当前等级、经验值升级进度条、本周期剩余免费解锁次数。
  - **经验值获取规则说明（新增/强化）**：在个人中心显式提供「经验值获取规则」说明板块或提示弹窗，明确展示：
    - 每日签到：+10 XP（每日仅限首次）
    - 每日点赞作品：+1 XP（每日仅限首次）
    - 每日收藏作品：+1 XP（每日仅限首次）
    - 作品被他人点赞：+3 XP（单作品单用户每日仅限首次奖励）
    - 作品被他人收藏：+6 XP（单作品单用户每日仅限首次奖励）
    - 明确提示“同一天内重复点赞/收藏不再重复增加经验值”。
  - 基本记录：已点赞/收藏内容、已报名活动列表、签到状态。

#### 3.2.8 全局底部（Footer 同步优化）
- 页脚包含品牌名称、品牌描述/副标题、导航链接及版权信息。
- 页脚的品牌描述与版权信息严格绑定后台站点文案配置，保证后台更新后前台实时生效同步。

#### 3.2.9 全局组件
- 智能助手对话窗口：常驻悬浮入口，支持多轮问答。
- 点赞与收藏动效：基于 gsap 实现图标缩放与红心粒子动效。

### 3.3 后台管理页面（Admin）

#### 3.3.1 入口一：内容管理
- **案例管理**：列表增删改查、富文本编辑、分类配置、基础互动量设定。
- **项目库管理**：列表增删改查、付费类型（免费/会员/Pro）设置、成熟度状态配置、富文本编辑与标签分类。
- **城市组局管理**：活动增删改查、筛选配置、报名名单查看与导出。
- **商务与合作管理（新增）**：
  - 提供商务合作板块的富文本/模块化内容编辑与保存。
  - 提供「前台显示/隐藏开关」，开启时前台导航与页面可见，关闭时前台完全隐藏。

#### 3.3.2 入口二：网站文案与站点设置
- **品牌与导航配置**：Logo、站点名称、导航栏菜单项配置。
- **页脚文案配置**：
  - 提供「品牌描述/副标题」与「版权信息」编辑输入框。
  - 配置项保存后实时更新站点设置并同步至前端 Footer 展示。

#### 3.3.3 入口三：权益管理
- 配置各等级经验值阈值及各等级付费项目免费解锁额度。

#### 3.3.4 入口四：智能助手
- 助手名称、人设提示词及知识库问答对配置。

#### 3.3.5 入口五：账号管理
- 用户列表查看、账号状态管理与权限配置。

## 4. 业务规则与核心逻辑

### 4.1 经验值（XP）奖励与防刷规则
- **自然日判定**：以每日 00:00:00 至 23:59:59 为一个自然日周期。
- **主动行为奖励规则**：
  - 每日首次签到成功：+10 XP；当天重复签到无效。
  - 每日首次点赞任意作品：+1 XP；当天后续点赞不再增加 XP。
  - 每日首次收藏任意作品：+1 XP；当天后续收藏不再增加 XP。
- **被动互动奖励规则**：
  - 作品被他人点赞：作者 +3 XP（同一触发用户对同一作品在同一自然日内仅奖励 1 次）。
  - 作品被他人收藏：作者 +6 XP（同一触发用户对同一作品在同一自然日内仅奖励 1 次）。
- **取消与重复操作**：用户取消点赞/收藏后再重新点赞/收藏，若当日已发放过对应 XP，则不再重复发放；取消操作不扣除已获得的经验值。

### 4.2 项目卡片双标签规则
- 付费类型标签与后台 `access_level`（免费/会员/Pro）映射对应文本与配色。
- 成熟度标签与后台 `maturity`（如成熟产品/概念/测试版）映射对应文本与样式。
- 双标签固定悬浮展示于项目卡片封面图左上角，水平排列，超出边界自动换行或自适应对齐。

### 4.3 商务与合作板块可见性规则
- 状态为「显示」时：顶部导航栏展示「商务与合作」菜单项，路由正常可达。
- 状态为「隐藏」时：顶部导航栏自动剔除该项，用户直接输入 URL 访问时重定向至首页。

### 4.4 页脚文本动态同步规则
- 前端 Footer 组件直接消费后台配置的站点设置数据。
- 当管理员在后台修改保存页脚副标题或版权信息后，前端重新获取站点配置即可实时刷新呈现，无硬编码残留。

## 5. 异常与边界情况

| 业务场景 | 异常/边界描述 | 处理规则 |
|---|---|---|
| 同日多次互动 | 用户在同一天内连续点赞多个作品 | 仅第1次点赞发放 1 XP，后续点赞仅累加作品点赞数，不发放 XP 并正常反馈操作成功状态 |
| 商务板块关闭状态下访问 | 用户通过收藏夹或历史URL直接访问商务合作页 | 系统检测到板块处于隐藏状态，自动重定向至首页 |
| 标签字段缺失 | 历史项目数据未填写成熟度或付费级别 | 默认展示为「免费」及缺省成熟度状态，避免卡片布局破损 |
| 页脚文案为空 | 后台管理员清空了页脚副标题或版权信息 | 前端保持兜底默认排版，不出现 undefined 或空白碎裂 |
| 免费解锁额度耗尽 | 用户点击解锁付费项目但剩余额度为 0 | 弹窗明确提示免费额度已用尽，禁止扣减并引导升级 |
| 报名表单字段缺失 | 提交活动报名表单时未填写姓名或电话 | 校验拦截未填项并提示「请完善必填信息」 |

## 6. 验收标准

1. 用户在同一天内首次进行签到（+10 XP）、点赞（+1 XP）、收藏（+1 XP）时经验值正确增加；当日后续点赞与收藏操作仅更新互动状态，不再重复增加经验值；个人中心可清晰查看经验值获取规则说明。
2. 访问 AI 项目库，所有项目卡片左上角均规范展示「付费类型」与「成熟度」双标签，文字与样式与后台设置一致且视觉协调。
3. 顶部导航栏在「城市组局」右侧包含「商务与合作」入口，点击可进入对应页面；管理员在后台修改该板块内容可正常保存；后台关闭该板块显示开关后，前台导航与页面均不可见。
4. 管理员在后台修改页脚「品牌描述/副标题」与「版权信息」后，前台页面页脚区域可实时同步显示最新文案。
5. 访问付费项目详情页，未解锁状态下可调起等级解锁弹窗并正确扣减额度；活动详情页可正常提交报名表单且后台支持导出名单。
